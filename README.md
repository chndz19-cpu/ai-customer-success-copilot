# AI Customer Success Copilot

Portfolio prototype by Carlos Hernández Acosta.

## What it demonstrates
A browser-based Customer Success workflow that converts customer context into:
- account summary
- goals and success criteria
- risk signals
- next-best actions
- QBR talking points
- expansion signals

## Important
This prototype uses transparent front-end decision logic. It does not claim a live LLM/API integration or production readiness.

## Publish
Upload `index.html` to a static hosting provider (for example GitHub Pages, Netlify, Cloudflare Pages, or similar) and use the resulting public URL in your portfolio/job application.
